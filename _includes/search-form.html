{% comment %} Hacky strip of protocol to the sitesearch value we pass to Google {% endcomment %} {% assign url = site.url | replace_first: 'https://', '' %} {% assign url = url | replace_first: 'http://', '' %} {% assign url = url | replace_first: 'spdy://', '' %} {% assign url = url | replace_first: '//', '' %} {% comment %} No trailing slash. Google treats the sitesearch value as a literal URL prefix, and nothing on a root-hosted site starts with "host/" and ends there, so a slash here matches zero documents. The theme appends one because it assumes the site may live in a subdirectory. {% endcomment %}
